📊 Telecom Customer Churn Prediction & Retention Strategy
🚀 Project Overview

Built telecom churn prediction models using Logistic Regression, Random Forest, and XGBoost on 7,000+ customer records, achieving ROC-AUC = 0.846.

Final model: Logistic Regression
Reason: Stable probability outputs + high interpretability for business decision-making.

Developed an ROI-based retention strategy combining:

Customer Lifetime Value (CLV)
Churn Probability
Campaign Cost & Impact

Simulation under ₹50,000 budget shows targeted retention generates higher profit than blanket incentives.

🎯 Business Problem

Customer churn is expensive 💸
Telecom companies lose huge revenue when high-value customers leave.

Goal:

Predict customers likely to churn
Target only profitable customers for retention
Maximize ROI under limited marketing budget

🤖 Models Used
Model	Purpose
Logistic Regression	Final model (interpretable probabilities)
Random Forest	Non-linear baseline
XGBoost	High-performance boosting model
📈 Model Performance

Best ROC-AUC Score: 0.846
